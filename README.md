===========================
Marketing Tools Website
===========================

By: [nerdk enterprises ]

This is a modern, mobile-friendly marketing toolkit website designed for easy customization and clean visuals.

---------------------------------------
FILES
---------------------------------------

📁 MarketingToolsSite/
├── index.html       → Main content file
├── style.css        → Styling and design
├── script.js        → Loading screen logic
├── README.txt       → Info and usage guide

---------------------------------------
HOW TO CUSTOMIZE
---------------------------------------

1. Open index.html
   - Change "Tool Name 1", "Tool Name 2", etc.
   - Replace "YOUR-LINK-HERE" with your actual tool URLs
   - Update the welcome text and subtitle

2. Open style.css
   - Modify background or colors if desired
   - Fonts used: Orbitron & Rajdhani (already linked)

3. Open script.js
   - Change loading time by editing `setTimeout()` (default 2000ms = 2 seconds)
